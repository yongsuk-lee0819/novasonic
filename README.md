# 노바소닉 (NOVASONIC) 상세페이지

17MHz 초고주파 홈케어 디바이스 노바소닉의 제품 상세페이지입니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 상세페이지 본문. 외부 라이브러리·폰트 의존성 없는 단일 파일 |
| `lifestyle.jpg` | 실버·화이트 색상과 패키지가 함께 나온 정식 모델 컷 (1097×1434). SNS 공유 썸네일(OG 이미지)로도 사용 |
| `device.jpg` | 제품 본체 컷 |

초기 이미지 버전(`detail-0510.jpg`)은 "This page requires JavaScript to display" 문구가
그대로 찍혀 있어 삭제했습니다. 필요하면 git 히스토리에서 복원할 수 있습니다.

## 로컬에서 확인하기

브라우저로 `index.html`을 바로 열면 됩니다. 별도 빌드 과정이 없습니다.

```bash
# 또는 로컬 서버로 확인
python3 -m http.server 8000
# http://localhost:8000
```

## 배포

정적 파일 하나뿐이라 어떤 정적 호스팅에도 그대로 올릴 수 있습니다.

**GitHub Pages**

1. 저장소 `Settings` → `Pages` 이동
2. `Source`를 `Deploy from a branch`로 선택
3. 브랜치는 `main`, 폴더는 `/ (root)` 선택 후 저장
4. 1~2분 뒤 `https://yongsuk-lee0819.github.io/novasonic/` 에서 확인

**Netlify / Vercel**

저장소를 연결하면 됩니다. 빌드 명령은 비워두고, 배포 디렉터리는 저장소 루트로 지정합니다.

## 본문 출처

1차 자료(`노바소닉 상세페이지.docx`, `노바소닉 제품 소개서.pptx`)로 초안을 작성한 뒤,
채팅으로 전달받은 완성 디자인 목업 PDF(860×32133pt, 전자상거래법 표준 정보 고시 포함)를
최신 기준으로 삼아 사양·모드 구성·사용법·법정 고시 정보를 갱신했습니다.

## 배포 전 확인 목록

- [x] **FDA** — 목업 PDF는 "미국 FDA 인증"이라는 표현을 반복해서 사용하지만,
      실제로는 **인증이 아닌 등록(registration)** 이라는 점을 이미 확인한 상태라
      페이지에는 계속 `미국 FDA 등록`으로만 표기했습니다. 목업 원문을 그대로 옮기지 않았다는 점을
      알려드립니다 — "FDA 인증"이라는 표현은 등록과는 다른 법적 의미라 사용을 권장하지 않습니다.
- [x] **학술 인용(SCIENTIFIC DATA 섹션) 미반영** — 목업 PDF에는 PMID 4건을 인용한 학술 근거 섹션이
      있었습니다. PubMed에서 확인한 결과 4건 모두 실존 논문이지만, 전부 **Sofwave 등 병원용
      고강도 초음파 기기**(의도적 열 손상으로 콜라겐 재생을 유도하는 기전)에 대한 연구였습니다.
      노바소닉의 "Non-Heat(비열성)" 설계 주장과 정반대 기전의 기기를 인용하는 셈이라
      오해 소지가 있어 이 섹션은 페이지에 넣지 않았습니다.
      (검증한 논문: Hongcharu 2023 PMID 36757157, Gold & Biron 2024 PMID 38031530,
      Wang 2021 PMID 34417390, Fabi 2015 PMID 25709486 — 전부 Sofwave/MFU 계열 병원용 기기 연구)
- [x] **피부 층별 침투 깊이·콜라겐/엘라스틴 합성 촉진 주장 미반영** — 목업 PDF에는 표피층 10~17MHz,
      진피층 7~10MHz(콜라겐·엘라스틴 합성), 근막층 3MHz 이하 등 구체적 침투 깊이(mm)와 생리학적
      효능을 명시한 섹션이 있었으나, 의료기기 수준의 효능 주장이라 페이지에는 넣지 않았습니다.
- [x] **"세계 최초 / 유일"** — 절대적 표현은 객관적 실증 자료가 있어야 사용할 수 있어 제외했습니다.
- [x] **경쟁사 비교** — 목업 PDF의 비교는 "타사 제품", "일반 평면 헤드"처럼 실명 없이 일반화되어
      있어 비방광고 소지 없이 그대로 반영 가능했습니다 (평면 헤드 대비 접촉면적 30% 향상 등).
      다만 이전 스펙 이미지에 있던 "듀얼소닉 프로페셔널 309g 대비 45% 경량"처럼 **경쟁사를 실명으로
      비교하는 문구**는 여전히 제외했습니다.
- [x] **미백 / 혈류 개선 등 효능 표현** — 제품 분류(의료기기 여부)에 따라 사용이 제한되므로 제외했습니다.
- [x] **사용 전원 표기** — 목업 PDF의 전자상거래법 표준 정보 고시에서 `정격전압/소비전력: 100V-240V,
      50Hz`로 공식 확인되어, 기존에 갈렸던 `110~220V 60Hz` / `100-240V` 표기를 이 값으로 통일했습니다.
- [x] **브랜드 표기** — "주식회사 케이메디코스" 법인 인증서와 사업계획서로 확인. K-MEDICOS는 판매·유통사,
      대정에코테크는 제조사(표준 정보 고시에도 "주식회사 대정에코테크"로 명시)로 유지했습니다.
- [x] **A/S 문의처 — 번호 2건 확인 필요** — 채팅으로 받은 번호 `010-3790-3782`를 페이지 전체에
      사용했습니다. 다만 목업 PDF의 전자상거래법 표준 정보 고시에는 다른 번호
      `+82-31-366-3977`(A/S 책임자 번호, 유선)가 적혀 있었습니다. 둘 다 유효한 번호일 수 있으니
      (예: 하나는 고객 상담용 휴대폰, 하나는 법정 고시용 대표번호) 어느 것을 표준 정보 고시란에
      쓸지 확인해 주세요. 현재는 두 곳 모두 `010-3790-3782`로 통일해 두었습니다.
- [x] **판매처 링크** — K-MEDICOS 자사몰(`https://kmedicosgroup.cafe24.com/`)로 확정,
      히어로 CTA 버튼 · 하단 구매 섹션 · 푸터 세 곳에 반영했습니다.
- [x] **모델 컷 · 제품 컷 교체** — 채팅으로 전달받은 정식 제품 이미지(실버·화이트, 패키지 포함)로
      `lifestyle.jpg`를, 같은 이미지에서 크롭한 고해상도 컷으로 `device.jpg`를 교체했습니다.
      원본 이미지 패키지 박스에는 "FDA" 배지가 인쇄되어 있지만, 이미지는 그대로 쓰고 본문 문구만
      "FDA 등록"으로 유지했습니다.
- [x] **1회 충전 사용 시간** — **완충 후 최대 2시간**으로 확정. 목업 PDF의
      "1회 충전으로 2시간 이상 사용가능!" 문구와도 일치합니다.
- [x] **모드 구성 전면 개편** — 기존에는 `3/7/10/13/17MHz` 단순 5단계로 표기했으나, 목업 PDF 기준
      **4가지 모드(링클즈 12분 / 리프팅 12분 / 타이트닝 15분 / 안티에이징 15분) × 1~5단계 강도**
      구조로 다시 만들었습니다. "5단계 주파수 모드" 섹션을 "4가지 맞춤 모드" 섹션으로 교체했습니다.
- [x] **제품 구조 다이어그램 추가** — Curved Head / LCD 디스플레이 / 모드 변경 버튼 / 세기 변경 버튼 /
      전원 버튼 / 충전 단자를 라벨로 정리했습니다.
- [x] **사용 방법 6단계로 교체** — 목업 PDF의 공식 절차(물기 제거·도포 → 전원 켜기 → 모드 선택 →
      강도 선택 → 마무리 케어 → 세척·보관)로 교체하고, "하루 한 가지 모드·15분 이내 사용" 주의문을
      추가했습니다.
- [x] **전자상거래법 표준 정보 고시 섹션 신설** — 품명(Ultra Skin Care Device), 정격전압/소비전력,
      제조자, 제조국, 크기/무게, 주요 사양, 품질보증기준, A/S 연락처를 목업 PDF의 법정 고시 문구
      그대로 반영했습니다.
