# 노바소닉 (NOVASONIC) 상세페이지

17MHz 초고주파 홈케어 디바이스 노바소닉의 제품 상세페이지입니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 상세페이지 본문. 외부 라이브러리·폰트 의존성 없는 단일 파일 |
| `lifestyle.jpg` | 실버·화이트 색상과 패키지가 함께 나온 정식 모델 컷 (1097×1434). SNS 공유 썸네일(OG 이미지)로도 사용 |
| `device.jpg` | 제품 본체 컷 |

초기 이미지 버전(`detail-0510.jpg`)은 "This page requires JavaScript to display" 문구가
그대로 찍혀 있어 삭제했습니다. 필요하면 git 히스토리에서 복원할 수 있습니다.

## 로컬에서 확인하기

브라우저로 `index.html`을 바로 열면 됩니다. 별도 빌드 과정이 없습니다.

```bash
# 또는 로컬 서버로 확인
python3 -m http.server 8000
# http://localhost:8000
```

## 배포

정적 파일 하나뿐이라 어떤 정적 호스팅에도 그대로 올릴 수 있습니다.

**GitHub Pages**

1. 저장소 `Settings` → `Pages` 이동
2. `Source`를 `Deploy from a branch`로 선택
3. 브랜치는 `main`, 폴더는 `/ (root)` 선택 후 저장
4. 1~2분 뒤 `https://yongsuk-lee0819.github.io/novasonic/` 에서 확인

**Netlify / Vercel**

저장소를 연결하면 됩니다. 빌드 명령은 비워두고, 배포 디렉터리는 저장소 루트로 지정합니다.

## 배포 전 확인 목록

두 자료의 내용이 서로 어긋나거나, 표시광고법상 실증 자료가 필요한 항목입니다.
확인 후 반영해야 합니다.

- [x] **FDA** — 자료에는 "FDA 인증 획득"과 "FDA 진행 중"이 섞여 있었으나,
      실제로는 **인증이 아닌 등록(registration)** 으로 확인되어 `미국 FDA 등록`으로 표기했습니다.
      등록은 승인·인증과 다른 절차이므로 "FDA 인증", "FDA 승인" 표현은 사용하지 마세요.
- [ ] **"세계 최초 / 유일"** — 절대적 표현은 객관적 실증 자료가 있어야 사용할 수 있어
      현재 페이지에서는 제외했습니다.
- [ ] **경쟁사 비교 문구** — 자료의 경쟁사 실명 언급 및 "불량 모방 제품" 표현은
      비방광고 소지가 있어 제외하고, 일반적인 대역 비교로 대체했습니다.
- [ ] **"타사 대비 5배"** — 근거 자료가 있으면 각주와 함께 추가 가능합니다.
- [ ] **미백 / 혈류 개선 등 효능 표현** — 제품 분류(의료기기 여부)에 따라 사용이 제한되므로
      현재 페이지에서는 제외했습니다.
- [ ] **사용 전원 표기** — 상세페이지 문서는 `110~220V 60Hz`, 소개서는 `100-240V`로 다릅니다.
      현재는 충전 전압(`DC 5V 2A`)만 기재했습니다.
- [x] **브랜드 표기** — 드라이브에서 "주식회사 케이메디코스" 법인 인증서 폴더와
      "K-MEDICOS Business Plan 2025" 문서를 확인했습니다. K-MEDICOS는 실제 등록 법인(판매·유통사)이고
      대정에코테크는 제조사로 보입니다. 현재 페이지 표기(상단 K-MEDICOS, 푸터 제조 대정에코테크)를 유지했습니다.
- [x] **A/S 문의처** — `010-3790-3782`로 확정, 제품 사양 표와 푸터에 반영했습니다.
- [x] **판매처 링크** — K-MEDICOS 자사몰(`https://kmedicosgroup.cafe24.com/`)로 확정,
      히어로 CTA 버튼 · 하단 구매 섹션 · 푸터 세 곳에 반영했습니다.
- [x] **모델 컷 교체** — 채팅으로 전달받은 정식 제품 이미지(실버·화이트 색상, 패키지 포함)로 교체했습니다.
      이 이미지의 패키지 박스에는 "FDA" 배지가 인쇄되어 있는데, 배지 자체는 그대로 두었지만
      본문 문구는 여전히 "FDA 등록"으로 유지했습니다 (인증이 아닌 등록이라는 확인 사항은 변하지 않았습니다).
- [ ] **device.jpg 해상도** — 194px 폭이라 낮습니다. 고해상도 제품 단독 컷이 있으면 교체해주세요.
- [ ] `하루 12분` — 권장 사용 시간이 맞는지 매뉴얼과 대조
- [x] **1회 충전 사용 시간** — 문서마다 8시간 / 약 45분으로 갈렸으나, **완충 후 최대 2시간**으로 확정
      받아 제품 사양·디자인 섹션에 반영했습니다.
- [x] **출력 모드 5단계 값** — 문서마다 `3/7/10/13/17MHz` / `1/3/7/10/17MHz`로 갈렸으나,
      **`3/7/10/13/17MHz`**로 확정 받았습니다 (기존 페이지 값과 동일, 변경 없음).
- [ ] **경쟁 제품 대비 무게 비교** — 새 스펙 이미지에 "듀얼소닉 프로페셔널 309g 대비 45% 경량"이라는
      경쟁사 실명 비교가 있었으나, 비방광고 소지가 있어 페이지에는 넣지 않고
      "스마트폰 수준의 무게"로 순화했습니다. 근거자료와 함께 꼭 넣고 싶으시면 알려주세요.
