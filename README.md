# 노바소닉 (NOVASONIC) 상세페이지

17MHz 초고주파 홈케어 디바이스 노바소닉의 제품 상세페이지입니다.

## 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 상세페이지 본문. 외부 라이브러리·폰트 의존성 없는 단일 파일 |
| `detail-0510.jpg` | 초기 이미지 버전. 현재는 SNS 공유 썸네일(OG 이미지)로만 사용 |

## 로컬에서 확인하기

브라우저로 `index.html`을 바로 열면 됩니다. 별도 빌드 과정이 없습니다.

```bash
# 또는 로컬 서버로 확인
python3 -m http.server 8000
# http://localhost:8000
```

## 배포

정적 파일 하나뿐이라 어떤 정적 호스팅에도 그대로 올릴 수 있습니다.

**GitHub Pages**

1. 저장소 `Settings` → `Pages` 이동
2. `Source`를 `Deploy from a branch`로 선택
3. 브랜치는 `main`, 폴더는 `/ (root)` 선택 후 저장
4. 1~2분 뒤 `https://yongsuk-lee0819.github.io/novasonic/` 에서 확인

**Netlify / Vercel**

저장소를 연결하면 됩니다. 빌드 명령은 비워두고, 배포 디렉터리는 저장소 루트로 지정합니다.

## 본문 출처

## 배포 전 확인 목록

두 자료의 내용이 서로 어긋나거나, 표시광고법상 실증 자료가 필요한 항목입니다.
확인 후 반영해야 합니다.

- [x] **FDA** — 자료에는 "FDA 인증 획득"과 "FDA 진행 중"이 섞여 있었으나,
      실제로는 **인증이 아닌 등록(registration)** 으로 확인되어 `미국 FDA 등록`으로 표기했습니다.
      등록은 승인·인증과 다른 절차이므로 "FDA 인증", "FDA 승인" 표현은 사용하지 마세요.
- [ ] **"세계 최초 / 유일"** — 절대적 표현은 객관적 실증 자료가 있어야 사용할 수 있어
      현재 페이지에서는 제외했습니다.
- [ ] **경쟁사 비교 문구** — 자료의 경쟁사 실명 언급 및 "불량 모방 제품" 표현은
      비방광고 소지가 있어 제외하고, 일반적인 대역 비교로 대체했습니다.
- [ ] **"타사 대비 5배"** — 근거 자료가 있으면 각주와 함께 추가 가능합니다.
- [ ] **미백 / 혈류 개선 등 효능 표현** — 제품 분류(의료기기 여부)에 따라 사용이 제한되므로
      현재 페이지에서는 제외했습니다.
- [ ] **사용 전원 표기** — 상세페이지 문서는 `110~220V 60Hz`, 소개서는 `100-240V`로 다릅니다.
      현재는 충전 전압(`DC 5V 2A`)만 기재했습니다.
- [ ] **브랜드 표기** — 제조사는 대정에코테크, 페이지 상단 표기는 K-MEDICOS입니다.
      유통사/브랜드 관계가 맞는지 확인해 주세요.
- [ ] A/S 문의처, 판매처 링크 추가
- [ ] 제품 실물 사진 추가 (현재 텍스트만으로 구성)
